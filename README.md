# Эмулятор ADAM-5510M (Python)

Учебный эмулятор контроллера ADAM-5510M с модулями ADAM-5050 ×2, ADAM-5024, ADAM-5017 и
двухкоординатным плоттером на двух шаговых двигателях. Программы на C запускаются в нём как есть
(`#include "5510drv.h"`, `Set5050`, `Get5050`, `ADAMdelay`, …).

## Запуск

```
pip install pycparser
python main.py                      # окно эмулятора
python main.py examples/arrows_diag.c
python main.py prog.c --headless --svg out.svg   # без окна: выполнить и сохранить рисунок
```

Нужен Python 3.8+ с tkinter (в Windows он ставится вместе с Python). В окне: **Файл → Открыть…** (Ctrl+O),
**Пуск** (F5) / **Стоп**, выпадающий список **Скорость** (×1 — реальное время, «Максимум» — без задержек).
Нажмите кнопку Stand_By — пятая кнопка сверху в левой колонке второго ADAM-5050 (№1, канал 4), — чтобы программа
вышла из ожидания. Кнопка **Плоттер** открывает окно рисунка (Сброс, Сохранить SVG, размер поля).

## Подключение (по вашей схеме)

| Слот | Каналы | Что это |
|---|---|---|
| ADAM-5050 №0 | 0–3 | обмотки A, B, C, D двигателя X |
| ADAM-5050 №0 | 4 | Work — перо (1 = опущено, 0 = поднято) |
| ADAM-5050 №1 | 0–3 | обмотки A, B, C, D двигателя Y |
| ADAM-5050 №1 | 4 | Stand_by — кнопка |

Двигатель делает шаг, когда обмотки переходят в соседнюю комбинацию цикла `1001 → 1100 → 0110 → 0011`
(вперёд) или в обратную сторону (назад). **4 шага = 1 мм.** Перескок через одну фазу двигатель проходит
по инерции в прежнем направлении (в окне плоттера пишется счётчик таких перескоков). Если каретка
уходит дальше поля больше чем на 1 мм — «упор», дальше она не едет.

## Поддерживаемый C

`int/short/char/unsigned/float`, одномерные массивы, указатели на переменные и элементы массивов
(`&x`, `&a[i]`, `*p`, `p[i]`), функции с параметрами и рекурсией, `if/else/for/while/do/switch`,
`break/continue/return`, все операторы, `#define NAME значение`, `printf` (`%d %u %x %c %s %f`), `puts`.
Нет: `struct/union/enum/typedef`, `goto`, многомерных массивов, макросов с параметрами.

Ошибки компиляции выводятся в консоль как у вас: `Строка N: неизвестная переменная 'x'`,
отсутствие `main` — `Критическая ошибка - функция main() не найдена`. Ошибки выполнения (деление на ноль,
выход за границы массива, неверный слот) — `Runtime-ошибка (строка N): …`.

## Функции драйвера

| Функция | Что делает |
|---|---|
| `Set5050(&знач, слот, канал, ABit)` | записать бит |
| `Get5050(слот, канал, ABit, &перем)` | прочитать бит |
| `Set5024(&знач, канал, …)` | показать значение на канале ADAM-5024 |
| `Get5017(&перем, канал)` | прочитать вход ADAM-5017 (значение задаётся ползунком в окне, 0…10) |
| `ADAMdelay(мс)` | пауза |
| `Init5024(...)`, `LED_init()` | ничего не делают (принимают любые аргументы) |
| `ReadInt()` | прочитать число, введённое в строку «Ввод» |

## Допущения (мне неоткуда было их узнать — проверьте)

* **Какие каналы в какой колонке.** Левая колонка кнопок — каналы 0–7, правая — 8–15.
* **Режимы `AByte` и `AWord`:** `AByte` — «канал» это номер байта (0 или 1), `AWord` — все 16 каналов.
* **Сигнатуры `Set5024`, `Get5017`** угаданы по `Set5024(&k, 2, 0)`; `Get5017` принимает аргументы в любом порядке.
* **Поле плоттера** по умолчанию 600 × 400 мм (меняется в окне плоттера или `--field 500x300`).
* **Начальная фаза** двигателя неизвестна: первая допустимая комбинация обмоток считается точкой отсчёта.
* Состояния кнопок не сбрасываются между запусками, как и положение каретки (кнопка «Сброс» в окне плоттера).
